# Data Science Group Project Rubric

Unit: DATA3888 / Applied Data Science Project
Scale: 1–5 per criterion. Downstream systems MUST convert scores to percentages
(`score / 5 * 100`) and MUST NOT display raw tallies.

## Technical Implementation
Assesses correctness of models, pipelines, and code structure.

## Data Wrangling
Assesses cleaning, joining, and documentation of messy source data.

## Communication
Assesses clarity of written and verbal scientific communication.

## Collaboration
Assesses reliability, peer support, and equitable contribution to the team.

## Reproducibility
Assesses notebooks, seeds, environment files, and rerun instructions.
